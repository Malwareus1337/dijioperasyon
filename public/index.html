ÇOKLU BİLGİSAYAR CANLI SENKRON

Firebase Realtime Database Bağlantısı

Ofisteki tüm .exe uygulamalarının aynı veritabanını anlık senkron kullanmasını sağlar.

Durum kontrol ediliyor...

Ücretsiz 1 Dakikalık Firebase Kurulum Adımları

  1. console.firebase.google.com adresinden ücretsiz bir proje oluşturun.
  2. Sol menüden Build → Realtime Database bölümüne girip Create Database butonuna tıklayın (Başlangıç için Start in test mode seçebilirsiniz veya kural şifresi kullanabilirsiniz).
  3. Veritabanı ekranının üst kısmındaki https://...-default-rtdb.firebaseio.com (veya .firebasedatabase.app) adresini kopyalayıp aşağıdaki alana yapıştırın.
  4. Bağlandığınız anda mevcut tüm personelleriniz, şifreler ve geçmiş raporlar otomatik olarak Firebase'e aktarılır!
Not: Ayarı kaydettikten sonra oluşan firebase-config.json dosyasını diğer bilgisayarlarda .exe dosyasının yanına koyabilir veya aynı ayar ekranından bir kez girebilirsiniz.
🚀

Uzaktan Uygulama Güncelleme Yayınla (Tüm .exe'ler)

Sürüm: v1.0.0

Nasıl Çalışır?

  1. Yeni derlenen tek parça Dijipin-Operasyon-Takip.exe dosyasını doğrudan indirilebilir bir adrese yükleyin (Örn: GitHub Releases .exe linki, kendi sunucunuz/CDN veya Dropbox ?dl=1 doğrudan linki).
  2. Aşağıya bir üst sürüm numarasını (Örn: 1.0.1) ve doğrudan .exe indirme linkini yazıp Güncellemeyi Yayınla butonuna basın.
  3. Firebase üzerinden açık olan tüm ofis bilgisayarlarının üst barında anında 🚀 Güncelle (v1.0.1) butonu belirir; tıklayan personelin uygulaması yeni .exe'yi indirip kendini otomatik yenileyerek yeniden başlar.
İpucu: Güncelleme butonunu gizlemek isterseniz link alanını boş bırakıp kaydedebilirsiniz.
